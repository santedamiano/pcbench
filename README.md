# PCBench

PCBench is a web application for storing PC hardware configurations and benchmark results.

## Technologies

- Angular
- Node.js
- Express
- SQLite

## Development Environment

- Operating System: Windows 10
- Node.js: v23.5.0
- npm: 10.9.2
- Angular CLI: 19.2.27
- TypeScript Compiler: Version 5.7.3

The backend is written in JavaScript and runs using Node.js v23.5.0. The Angular frontend is written in TypeScript and compiled using the TypeScript compiler included with the Angular project.

## Backend

From the root of the project, run:

```bash
cd backend
npm install
node server.js
```

## Frontend

From the root of the project, run:

```bash
cd frontend
npm install
npm start
```
